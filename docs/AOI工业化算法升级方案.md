# AOI 工业化算法升级方案（不用 DL / 不做模型训练）

日期：2026-10-21状态：**待评审（改检测主线，按 QUALITY_DEBT 规矩须先有票+ 反驳过审）**

---

## 一、结论先行

1. **「不用 DL」与「能工业化」不冲突。** 工业 AOI 主流（Schema AOI、Orbotech、Camtek、国产 TAIJI/劲拓/矩子）的主力算法是模板比对 + 统计容差 + 形态学 + 几何特征判定，CNN 只作为"辅助分型/降假点"的二线手段。纯经典算法做到可工业化的门槛不在模型，在**判别信息的组织方式**。
2. **本仓当前的瓶颈不是标定。** 已实测：漏检 GT 内 |diff| 峰值 110/110≥50（阈值仅 30），背景噪声底 p99 仅 14，配准对峰值增益**恒为 0**。信号早就够阈值，**配准/位深/亚像素这条线已证伪**。
3. **真实死因是"用全局统计量判一个不可分的二分类"。** `PcbMissAuditor` 归因 144 个漏检：lop 闸 51 + area<min 36 = **60%**；全部 144 个 `RawDiffPx>0`（不是没检出，是检出后被闸门杀掉）。
4. **灰度单一维度上鬼影与小面积浅咬真缺陷高度重叠**，所以任何"再调一版阈值/形态学尺寸"都无效。要突破必须引入**正交的判别信息**（局部纹理结构 / 空间统计基线 / 多金板一致性），这三样都不需要模型训练。

## 二、行业做法调研 → 与本仓差距对照

| 行业标准做法 | 目的 | 本仓现状 | 差距 |
|---|---|---|---|
| **Golden Board Approach**：用 5~10~20 块良品建"超级模板"，系统**学习正常波动**，阈值按 分布±kσ 定，而非绝对值 | 把"绝对阈值"换成"统计容差"，天然抑制批次色差、工艺波动造成的假点 | 只用单张template，全局阈值 | **缺（最大差距）** |
| **分区阈值窗口**（BGA 区 115~145 / 阻容区 100~130 / 金手指 90~155） | 铜厚、油墨、光照在各区灰度不同，全局阈值必然一边过杀一边漏检 | 全图单阈值 | **缺** |
| **缺失/多余特征分开判定**（ref 有 test 无 = missing candidate；test 有 ref 无 = extra candidate，两类分开走） | 断路与短路的成因、判据、后续处理完全不同，混在 |absdiff| 一起判 | 部分有（neg 分支），但阈值不分区 |
| **二值铜掩膜比对** + 逐 ROI 分割，只在元件/焊点位置检测 | 跳过基板空白区，既提精度又提速度 | 差分覆盖全图 | 缺 |
| **多角度/多光源成像** + 光照归一化 | 用斜向光的阴影表达高度差（虚焊、偏移） | 单光源合成图 | 光学侧限制，算法侧无解，可列为产线级建议 |
| **差分 + 动态阈值 `dyn_threshold` + 定向形态学**（按特征方向选SE：线状缺陷用rect、斑点用circle） | 减少"清理操作把要找的窄断裂/桥连一起抹掉" | 有开/闭，SE 不随特征走| 缺方向性 |
| **像素投票法**（良品序列逐像素投票 / 少数异常片直接排除） | 小概率缺陷在投票中被自然抑制，无需人为设阈 | 缺 | **建议评估** |
| **失败语义分离**：判定为「缺陷 / 可接受工艺变异 / 采集无效（失焦过曝配准失败）」 | 过杀的一大部分其实是采集问题，不该算到算法头上 | 二值判定 | **缺（工业必备）** |
| **必设人工复判工位**，指标看 **FCR（假点率）与 Escape Rate（漏放率）**，而非单一准确率 | 工业 KPI 就是这两个数，与"整体准确率"不是一回事 | 有 F / mAP，无 FCR / 每板假点数 | **指标口径需换** |

## 三、改造方案（按"是否引入新判别信息"排序）

### P0 — 多金板统计容差场（Golden Board Approach）
**做什么**：每款 PCB 收 5~10 块良品，逐像素求μ(x,y)、σ(x,y)，落盘为`sigmaMap`。判定从`|diff| > T`改为**标准化残差**：

```
z(x,y) = |I_test − μ| / max(σ, σ_floor)   判NG: z > k
```

**为什么能突破**：鬼影/批次色差/油墨波动这类**空间上大面积、幅值小**的扰动，σ 大→ z 自动被压住；真缺陷是**局部尖锐异常**，σ 小 → z 拉高。这正是当前全局阈值分不开的那两类，且完全不涉及训练。
**成本**：需要为每款板采集良品（这是产线常态，不是额外负担）；配方需新增两个资源路径字段。
**风险**：σ_floor 太小会把噪声放大成缺陷；需在拟合集标定。

### P1-2 分区阈值 + 差分符号分判
引入 ROI 分区表（可由 Gerber 或治板图生成），每区一套 `{diffThreshold, minArea, directionSE}`。对应行业"分区阈值窗口"。

### P2 — 三态输出与工业 KPI
① 输出改为 OK / NG / **复判（疑似）/ 采集无效**；② 采集有效性自检（失焦/过曝/配准残差超限 → 直接判"无效，请重拍"，不计入过杀）；③ 评测口径增加 **FCR（每板假点数）** 与 **Escape Rate（漏放率）**。

### 明确不做（已证伪或超出约束）
位深提升、亚像素配准精化、C1 FWHM 足迹、D1 seed z、梯度补偿、工作点下移、LOP 深度豁免、BIN分箱、m_min、SplitT/SplitC、GrowBoxElong。详见 `docs/QUALITY_DEBT.md` 与 `reports/lopdepth_falsification.md`。

## 四、实施顺序与验收纪律

| 阶段 | 内容 | 产出 |

| S5 | 分区阈值 + 差分符号分判 | 需治板图/Gerber ROI 分区 |

**纪律（不可破）**：
- `data/official_test`（500 对）**仍是最终验收集，禁止调参**；拟合只用 `data/full` 中非 official_test 的 1000 对。
- 每轮改动必跑四集旧金标（external / holdout / mixed / samples）确认**零退化**。
-拟合集增益必须同时过 external + official_test 才能升配方（lds4 教训）。
- 改检测主线须先落本票并过反驳审查。

## 五、诚实的能力边界（须与业务方对齐）

- **8 位单分量 JPEG 源数据**决定了信噪比天花板；P0 两条能改善判别，但无法把浅咬/鬼影在**幅值维度**分开——能分开靠的是结构信息。
- 工业界真正的鲁棒性一半来自**光学**（多光源、景深、畸变校正）。当前单光源数据集下，算法侧最多做到"不因全局波动过杀"，做不到"换批次仍然零调参"。
- 深度学习在此**不是必需但确实更省事**。不上 DL 意味着要靠 P0/P1 的工程化补足，这正是本方案的内容。

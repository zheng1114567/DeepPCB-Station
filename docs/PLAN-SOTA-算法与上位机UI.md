## 1. 目标拆解：差距到底在哪（用已有数据算，不猜）

官方 test 500 对实测（`reports/gbs_1.5/sota_eval_20261020_194737/sota_eval.md`）：GT 3140、Pred 3116。

| 层 | TP | 相对 GT 的缺口 |
|---|---|---|
| 忽略分型 IoU≥0.33（定位上界） | 3033 | 107 个 GT 没被合格框覆盖 |
| 严格分型 IoU≥0.33（可比口径） | **2461** | 679 |

拆开这 679：

| 损失来源 | 数量 | 占比 | 现有机制能否触及 |
|---|---|---|---|
| **A. 位置对、类型错** | **572** | 84% | `PosType`/`NegType` 两条启发式规则 |
| B. 有重叠但 IoU<0.33（其中 0.2–0.33 共 47 个） | 55 | 8% | `GrowBoxScale` 全局 1.5 已到顶 |
| C. 零重叠真漏检（最近 pred >60px） | 49 | 7% | 上游阈值/闸门，需新检出通道 |
| D. 一对一贪心冲突 | 3 | <1% | 评测器口径，不修 |

（679 = 3140 − 2461；直方图核对：IoU≤0 49 + 0–0.1 5 + 0.1–0.2 3 + 0.2–0.33 47 = 104 未过 IoU，加 572 类型错 = 676，余 3 为贪心一对一互斥。）

Pred 类型分布更直接暴露问题：

| 类 | GT (test) | Pred | 偏差 |
|---|---|---|---|
| open (1) | 659 | **995** | +336 溢出 |
| mousebite (3) | 586 | **230** | **−356 塌陷** |
| short / spur / copper / pinhole | 478/483/464/470 | 488/489/443/471 | 基本平衡 |

**这就是全部真相：分型不是"不够准"，是 open/mousebite 二分类吸干了 35% 的鼠咬。**
根因在 `PosType()`（L1275）：`SeversCopper(blob) || lateral/localW ≥ 0.8 || aspect ≥ 1.3` 三选一即判 OPEN，而 `aspect ≥ 1.3` 对任意线宽的缺口都极易成立——**这个阈值没有除以线宽，是个绝对量纲错误**。

第二层差距在排序，不在检测：

- 检出 F 97.0% 但 mAP11 只有 89.3%，**8 个点的落差几乎全来自置信度**——`PcbIcdarEvaluator` 里 `Conf = 候选面积`（注释自述"仅用于排序"）。面积排序会让大鬼影压过真缺陷，AP 天然塌。

所以四条线的 ROI 排序是：**分型（572）> 置信度标定（8 点 mAP）> 几何（47）> 补漏（49）**。这顺序和"先调 GrowBoxScale"直觉相反，但数据就是这样。

## 2. 算法设计

### 2.0 目标与判据（先定死，避免又一轮无票拧参）

| 阶段 | 判据（官方 test 500 对，同划分） | 说明 |
|---|---|---|
| G0 现状 | 检出 F 97.0 / mAP11 89.3；严格 78.7 / 68.7 | 已落盘 |
| G1 定位反超 | **检出 F ≥ 98.2%**（TP ≥ 3084，FP ≤ 20） | 检出层面只比"找没找到"，最硬（对手为论文 DL 模型） |
| G2 全口径反超 | **严格 mAP11 ≥ 98.6% 且 F ≥ 98.2%** | 论文可比口径，终极目标 |
| 保底 | 四集旧金标口径（external 480 / holdout / mixed / samples）**零退化** | 每轮必跑 |

**留出纪律**：`data/full` 的 1000 对（6873 个 GT 框，六类近均衡）作**训练/拟合集**；`data/official_test` 的 500 对**只做最终评测，禁止调参**；`data/external` 480 对继续当"未调参泛化集"。这条比任何参数都重要。

### 2.1 A 线：分型重构（收益最大，先做）

**问题定性**：现在两类分型都是"单阈值 + 绝对像素量纲"：

```csharp
// PosType, L1275-1289
if (typeRefine && SeversCopper(blob)) return "OPEN";
if (surround >= surroundMin) return "PINHOLE";
if (lateral / localW >= openBiteFrac) return "OPEN";   // 唯一带线宽归一化的一条
return aspect >= openAspectMin ? "OPEN" : "MOUSEBITE"; // ← 绝对阈值，主要误判源
```

`SeversCopper()`（L1344）也不稳：窗半径固定 12px，且靠 `severDilate` 补膨胀，对 2px 细线与 30px 宽走线的判据完全不同。

**设计**：把分型从"手写阈值"升级为**线宽归一化的物理特征 + 浅层决策树**（depth ≤ 5，规则可全量打印、可写进债页、仍是传统算子，不引入任何训练权重黑箱）。

10 个特征，全部可由现有中间量在**不新增图像遍历**的前提下算出（`distToSubstrate`、`copperRegion`、`NetLabels()`、`diffI`、`surround`、`area/aspect` 都已在手）：

| # | 特征 | 定义 | 物理含义 | 现状可得性 |
|---|---|---|---|---|
| f1 | `biteDepth/w` | `RobustMaxGray(blob, distToSubstrate)/localWidth` | 咬进铜线多深（0~0.5） | `ScaleFeatures` 已有 |
| f2 | `lateral/w` | 短边 / `localWidth` | 咬口横向占线宽比 | 已有 `openBiteFrac` 分子 |
| f3 | `severed` | 去 blob 后窗内铜连通数增量 ∈{0,1} | 是否真切断 | 已有 `SeversCopper`，需改成**自适应窗 = 3×localWidth** |
| f4 | `nets` | `UnionNets(...,2)` = 0/1/2 | 是否跨两块独立铜网 | 已有 |
| f5 | `parts` | `LocalCopperParts(blob, 6)` | 邻域铜分量数 | 已有（`NegType`） |
| f6 | `fill` | `area/(W*H)` | 形状实心度 | 一行 |
| f7 | `aspect` | 长宽比 | 细长程度 | 已有 |
| f8 | `polarity` | 缺铜=−1 / 多铜=+1 | 极性 | 调用点已知 |
| f9 | `dCopper/w` | 负极性 blob 到铜的距离 / w | copper（悬空铜渣）vs spur（挂线凸起） | `CopperGate` 已有 |
| f10 | `pin` | `surround ≥ surroundMin` | 被铜全包围 | 已有 |

**训练流程（离线，可复现）**：

1. 在 `DetectCore` 末尾加诊断口 `CollectFeatures`（复用现有 `CollectRejected` 模式），把每个候选的 f1..f10 + 框 + 匹配到的 GT 类型（IoU≥0.33 或中心落框，同口径）dump 成 tsv。
2. 新增 CLI：`--feature-dump --samples=data/full --exclude=data/official_test_ids.txt` → 得到 ~1.5 万条带标签候选。
3. 现有 Python 侧（`tools/` 下）跑 CART：5 折交叉验证 + 类别混淆矩阵，导出树为 `PosType`/`NegType` 的 if-else（或查表 + 线性打分），**规则原文入 `QUALITY_DEBT.md`**。
4. 反过度拟合闸：树在 train 折内准确率与 test 500 对准确率差 > 3pp 即判过拟合，砍深度重来。

**预期**：严格 TP 2461 → 2850±80（类型准确率 81%→94%），严格 mAP11 68.7%→**82~88%**。这一步不碰检出行为，旧金标口径**结构性零退化**（只改标签）。

**风险与对策**：分型一旦参与过滤（如 `TypeMinArea`）就会反向影响检出。**强约束：树只打标签、不参与任何闸门**，与现有 `typeMin = selectMin` 的解耦一致。

### 2.2 B 线：置信度标定（1 天拿 4~6 个 mAP 点）

`PcbIcdarEvaluator` 的 `Conf = area`，是 AP 掉 8 点的直接原因。改成单调打分：

```
score = σ( w0 + w1·ln(peakDiff) + w2·ln(area) + w3·(1−edgeFrac) + w4·severed + w5·nets + w6·fill )
```

- `peakDiff`（blob 内最大绝对差分）、`edgeFrac`（现成）与面积都是"真缺陷概率"的强信号；
- 权重用 2.1 的同一份 dump 做逻辑回归拟合（标签 = 是否命中 GT），**导出 7 个常数**硬编码，不引入运行时模型文件；
- 分型树叶子纯度可同时作为类别置信，供**每类 AP** 的类内排序用（mAP 是按类平均的，类内排序比全局排序更关键）。

**验收**：F 不变的前提下 mAP11 单调上升（每类都要看，不能靠 open 一类拉平均）。目标 +4~6 点。这条先做，因为它**不改变任何检出/抑制行为**，零回归风险。

### 2.3 C 线：逐框足迹估计（替代全局 GrowBoxScale=1.5）

> **已实证证伪（2026-10-21，train1000 全量）**：|diff| 剖面呈「热核平台→断崖→亚阈值裙边」双峰结构，τ∈[0.15,0.6] 输出逐位相同、τ=0.08 也仅占 GT 面积 19%（131 pred 落 GT 内 / 0 包住）。GT 完整足迹不对应任何固定 peak 分数比。代码保留、`footprintTau` 默认 0 关闭。证据：`reports/c1_*`、债页 v1.1.0 节。

债页结论"无 per-box 尺寸信号"有一个漏洞：**信号是有的，只是当时只找了"框外的平移/伸长"，没找"框内的幅度分布"**。

**机制：半高全宽（FWHM）足迹**

对每个候选，在 `|diff|` 上取行/列投影剖面 `P(y)`、`P(x)`，以 `peak × τ`（τ=0.5，可扫 0.35~0.6）为边界，取包含峰值的连续区间作为足迹：

```
x1..x2 = argmax 区间，使 |diff| 每列最大值 ≥ τ·peak
```

理由（有物理根据，不是新魔法）：模板差分对"缺陷掩膜"是近似线性的，`|diff|` 的空间分布就是缺陷足迹与边缘响应的叠加；GT 标的是"完整足迹"，恰好对应**半高**位置（阈值化 blob 是 30 灰度截断，天然只保留 >0.5·peak 的高置信核）。τ 是唯一新参数，且量纲无关。

**与已证伪方案的区别**（必须写清，避免重复踩坑）：

| 已证伪 | 为什么失败 | FWHM 为何不同 |
|---|---|---|
| `GrowBoxElong` 各向异性伸长 | 框已过大，伸长只会更糟 | 从 core 重新量足迹，可胀可缩 |
| `GrowBoxPad` 恒定加边 | 尺寸差是比例不是边距 | 按峰值的比例定界，非固定像素 |
| `GrowBoxScale` 全局 1.5 | 单一全局量拟合不了分布尾部 | **每框自己的 τ·peak**，天然按对比度自适应 |

**实现位置**：替换 `GrowBoxesToRegion()`（L1052）末端那段 `growBoxScale/growBoxElong/growBoxPad`（L1132-1153），保留 `BFS 生长` 作为初值；三个旧开关保留（=0 时逐像素等价），便于回滚。

**预期**：55 个近失里 30~40 个进入 IoU≥0.33；mAP11 +2~3。**必须同时验证 FP 不涨**（足迹膨胀会吞邻框 → 77 个 GT 的"最优重叠 pred"可能被邻居抢走）。

### 2.4 D 线：补回 49 个零重叠漏检（唯一需要"新检出机制"的地方）

49 个 = mousebite 17 + short 14 为主。既然最近 pred >60px，说明**上游根本没有候选**。分层处理，每一层都可独立开关：

**D1 局部自适应种子（弱对比漏检）**

> **已实证证伪（2026-10-21）**：z=(ad−μ)/(σ+ε) 统计窗含缺陷自身，z 上限=√((1−f)/f)，16×16 窗下 SeedZ≥3 结构性不可达；SeedZ 3~8 × 窗口 48/64 实测逐位等价 base。洪水测试（最宽松档）证明管道完好但 +80 候选全 FP / 0 TP——漏检 GT 峰值 |diff| 在噪声底以下。`seedZ` 默认 0 关闭。证据：`reports/d1_*`、债页 v1.1.0 节。

现有 `Threshold(diffI, 30, 32000)` 是全局固定灰度。补一路**局部 z 分数通道**：

```
z(x) = (|diff(x)| − median_w) / (1.4826·MAD_w)     // 16×16 滑窗，积分图 O(1)
种子：z ≥ 5 且 |diff| ≥ 12
生长：z ≥ 2.5（hysteresis）
```

- 全局 30 通道保留不变（强证据），z 通道只**加**候选，不做减法 → 对既有命中零影响；
- 平坦区 MAD≈0 会爆 z，故要求 `|diff| ≥ 12` 兜底（与现有 `edgeShallowDiff` 同思路）；
- 预期捞回 10~15 个弱对比 open/short。

**D2 线宽归一化面积下限**
`minBlobArea = 22` 对 30px 宽走线上的小咬口（真缺陷）过大，对 2px 细线又太松。改成：

```
minArea = clamp(0.25 · localWidth², 6, 22)
```

`localWidth` 已有。**注意**：这是闸门改动，必须只看 train 1000 对的 FP 增量，test 500 只验收。

**D3 细短路（1px）逃逸**
`bridgeThinRescue` 已处理相邻网桥，但 49 个里 short 14 个多为"细线在缝里、边缘解释被吃满"。用 f3/f4 的拓扑硬证据替代边缘解释（`BridgeSkipEdge` 的方向正确，建议在 `negAwayCu` 分支扩到"跨两网 + 距铜 ≤2px"）。

**D4 配准残差（与 E 线合并处理）**

### 2.5 E 线：亚像素配准而不糊边（梯度补偿差分）

> **已实证证伪（2026-10-21，train1000 全量）**：梯度补偿使检出 F −3.2pp / 严格 F −3.0pp / TP −257。补偿项 Gx·fx 在铜边量级 ±15 灰度，与弱缺陷信号（12~30）同阶，分数位移噪声把真信号一起减掉；IoU 中位未改善（0.542→0.544）而召回崩塌。整数配准已是该信号尺度最优工作点。`subpixelGradient` 默认 false 关闭。证据：`reports/e1_sub/`、债页 v1.1.0 节。

`RegisterSubPixel=true` 已被证伪（r1/r2：F 97.82/97.55，因为双线性重采样把铜边糊成斜坡，阈值 30 下制造整幅鬼影）。但**问题不在亚像素，在重采样**。

**机制：Lucas-Kanade 一步梯度补偿**

不重采样图像，改差分公式：

```
d(x,y) = test(x,y) − [ temp(x+dx, y+dy) + Gx·fx + Gy·fy ]
其中 dx,dy 为整数平移（沿用 TileShiftRegistration 的搜索），fx,fy ∈ [−0.5,0.5] 为抛物线细化的分数部分
Gx,Gy = 模板 Sobel 梯度（单帧预算一次）
```

- 图像保持原始锐度（不插值），但残差已补偿到亚像素 → 铜边残差从 ±2px 系统偏移降到 <1px；
- 成本：一次 Sobel（640×640，约 3ms）+ 每像素 2 次乘加；
- 位移场仍用现有 8 块 + 3×3 中值（`AlignSmooth` 的场估计可以复用，只是**不做图像插值**，只取值 + 梯度补偿）。

**验收指标**：GT 中心偏移中位（现 2.1px）→ <1.2px；铜边残留差分 >30 的像素数下降 ≥30%；FP 83 → ≤60。这是"结构性"改善，也是 G1 能否过 98.2% 的关键。

### 2.7 实施顺序与预算

| E1 | 梯度补偿亚像素 | — | 1.5d | ~~FP −25，偏移 −1px~~ → **证伪（−3pp）** |
| D2/D3 | 线宽归一化面积 / 拓扑救回 | A2 | 0.5d | recall +0.2 |

A1/B1/A2 = v1.0.0 已落地；C1/D1/E1 = v1.1.0 已实现并证伪关闭（默认关，生产逐位等价 v1.0.0）。据 train1000 实测，下一轮优先项为**分型混淆对特征**（分型损失 4.5pp > 定位/召回一切空间），D2/D3 次之。

单帧预算：现约 400ms 级（`EngineMs` 埋点），A1+B1 纯离线，C1 一次投影，D1 积分图一次，E1 一次 Sobel → **目标 ≤ 450ms/640×640**，超 500ms 即回退 D1。

## 5. 风险登记

| 风险 | 触发信号 | 应对 |
|---|---|---|
| 分型树在 test 上过拟合 | train 折准确率 − test 准确率 > 3pp | 砍深度到 4、只用 f1~f6（去掉 fill/aspect 这类易拟合量） |
| FWHM 吞邻框导致 FP 上升 | 官方 test FP > 90 或旧口径 external FP 上升 | τ 从 0.5 升到 0.6（更保守）；`growMaxScale` 夹住上限 |
| z 通道把噪点当缺陷 | samples 集 FP > 0.5% | 提高 `SeedZ` 到 6、要求 z 区必须与铜区相交 |
| 亚像素补偿反而放大噪点 | 中位偏移未降或 FP 上升 | 只在 `|diff| ≥ 12` 的铜边像素启用补偿 |
| UI 返工影响验收 | — | UI 与算法**严格并行**、不共文件；`SCOPE-UI` 第 14 条「检测/配方/Halcon/金标一律不动」继续有效 |

## 6. 一句话总结

**算法**：差距 84% 在分型（open 吞掉 356 个 mousebite，根因是绝对量纲的 `aspect ≥ 1.3`），8 个 AP 点在置信度（`conf=面积`），几何与漏检只占 16%。所以先做"分型树 + 置信度标定"这两件零回归风险的事，再动 FWHM 足迹、z 通道与梯度补偿亚像素——顺序反直觉，但每步都有 reports/ 的实测依据。

**UI**：配色已经合规，形态还停在 Web 仪表盘。改成直边、1px 硬边、双线凹陷状态栏、状态灯列、菜单/工具栏/底部页签的上位机骨架，圆角一律归零，24px KPI 数字退场，信息密度对齐 WinForms。样张见 `docs/ui-mockup-上位机.html`。

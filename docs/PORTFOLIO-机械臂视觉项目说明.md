## 五项核心工作

### 1. 手眼标定（D435i）

- 相机内参：出厂标定 + 现场复核；深度图与 RGB 图对齐
- 手眼矩阵：`AX = XB` 求解，安装方式（眼在手上 / 眼在手外）`【待确认】`
- 标定点位需覆盖实际工作空间，而非集中在视野中心
- 验证指标：重投影误差 / 抓取点位偏差 `【待补：mm】`

**可讲的技术点**：标定残差怎么统计、异常点怎么剔除、为什么标定点要覆盖工作空间边缘。

### 2. 真机 PLC 联调与部署

- 握手时序：触发 → 拍照 → 识别 → 位姿下发 → 抓取完成 → 复位
- 异常分支：超时、抓空、急停后的状态恢复
- 部署内容：现场安装、参数固化、连续运行验证
- 量化：单件节拍 `【待补：s/件】`、连续运行时长 `【待补】`

**可讲的技术点**：为什么握手要带超时与作废语义（与 DeepPCB-Station 的
`VOID/` 落盘、`CAPTURE_INVALID` 是同一套工业语义），现场断线重连怎么处理。

### 3. 上位机开发

- C# / WPF 单窗口工位界面：相机实时预览、识别结果、抓取状态、手动 / 自动切换、报警
- 与 DeepPCB-Station 的复用边界：`ICamera` 抽象、结果存储、配方、日志
- 量化：界面刷新 `【待补】`、从拍照到下发位姿的端到端耗时 `【待补】

### 4. YOLO 识别与抓取

- 数据采集与标注：类别数 `【待补】`、样本量 `【待补】`
- 训练 → 导出 ONNX → 部署（推理后端 `【待补】`）
- 精度：mAP `【待补】`、单帧推理耗时 `【待补：ms】`
- 抓取链路：检测框中心 + 深度值 → 相机坐标系 → 手眼矩阵 → 机器人基坐标系 → 抓取位姿

**可讲的技术点**：2D 检测到 3D 位姿的坐标变换链路、深度缺失/跳变的处理、
抓取点从框中心改为质心/主轴方向的原因。

### 5. 999 点标定

- 目的：`【待补：平面度补偿 / 畸变校正 / 工作空间映射 / 抓取高度补偿】`
- 方法：大网格点位采集 → 拟合 → 残差统计
- 结果：残差 `【待补：mm】`、覆盖范围 `【待补：mm×mm】`

**可讲的技术点**：为什么 9 点不够、点位数量与精度的关系、拟合模型怎么选
（仿射 / 二次曲面 / 薄板样条）。

## 与 DeepPCB-Station 的分工（简历组合叙事）

| 维度 | DeepPCB-Station | 机械臂视觉项目 |
|---|---|---|
| 场景 | 2D 裸板缺陷检测（离线回放） | 3D 引导抓取（**真机**） |
| 算法 | Halcon 传统管线（配准 / 差分 / 分型） | YOLO + 手眼变换 + 点标定 |
| 工程 | 工位壳、配方、复判、评测纪律 | 上位机、PLC 握手、现场部署 |
| 补什么 | 工程完整度、评测纪律、工业语义 | **真机、DL 部署、3D、机器人** |

**组合口径**：两个项目不重复造对方的长处——
DeepPCB 讲「一个人从零搭一台检测设备 + 严苛的评测纪律」，
机械臂讲「真机落地 + DL 部署 + 3D 视觉引导」。
面试时按岗位选主讲：上位机 / AOI 岗主讲 DeepPCB，算法 / 机器人岗主讲机械臂。

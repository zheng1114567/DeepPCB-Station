| (scale, pad) | 形式 | 检出 F | TP | FP | 卡0.2-0.33 |

| (1.5, 0) | 乘法·基线 | **96.96%** | 3033 | 83 | 47 |

| (1.3, 10) | 混合 | 75.10% | 2349 | 767 | 723 |

**加法全线劣于乘法，无一档破 97.0%**；纯加法有极陡悬崖（pad 10→20→30：96.4→24.5→1.1，因小框被同一绝对边距暴涨越过 GT）。这**反证**了恒定加法边距假设——pred/GT 是近似恒定**比值**（0.53×，正是乘法的形式），加法是错误函数形式。更关键：**框间尺寸方差是 per-box 的，而无任何 per-box 信号可依据**（diff 区仅框的 ~0.5×、GT 标注边距本身松散不一致），故**任何单一全局参数（乘或加）都拟合不了尺寸分布尾部**——逐框自适应在缺乏 per-box 尺寸预言信号时不可实现。GrowBoxPad **默认关**（=0 逐像素等价现状，代码保留为可回退基础设施）。

**结论（据实）**：**检出口径**（项目主口径）在**官方划分**上达 **97.0% F / 89.3% mAP11**（scale=1.5），距论文 DL 模型（VGG16-tiny + GPP，非传统模板差分法）F 98.2% 尚差 ~1.2 点，属跨范式差距。该差距已确认为**结构性**、**非末端缩放可弥合**：（a）IouBuckets[0]=49——始终 49 个 GT 无任何重叠 pred（mousebite 17 + short 14 为主，最近 pred>60px），属真检出缺失；（b）~48 个近失框卡 IoU 0.2-0.33，因**框间尺寸方差 + 均匀偏小**（非中心偏移，已由 scale=0 证伪偏移中位仅 2px）；纯调参（GrowBoxScale）天花板 = 97.0%，且 GrowBoxElong（异性伸长）与 GrowBoxPad（加法外扩）**均已实扫证伪**——单一全局几何参数无法拟合尺寸分布尾部。要反超 98.2% **只剩救回 49 硬漏检**这一条（需新检出机制、超出末端几何范畴、须另评估开闸）。严格分型（类型全对）仍受手工规则限制。旧口径四集零退化。证据：`reports/gbs_1.1–2.0/`、`reports/gbsv2_1.5|1.6/`、`reports/gbe_*/`。

## v1.0.0：分型树 + 置信度标定（2026-10-21）

**性质**：只改「标签」与「排序键」，**不动任何检出/抑制闸门**；检出口径（忽略分型）实测零退化。

### 诊断（为什么改这里）

官方 test 500 对（GT 3140）严格分型损失 679 = 3140 − 2461，逐层拆开：

| 来源 | 数量 | 占比 |
|---|---|---|
| **位置对、类型错** | **572** | 84% |
| 有重叠但 IoU<0.33（其中 0.2–0.33 共 47） | 55 | 8% |
| 零重叠真漏检 | 49 | 7% |
| 一对一贪心冲突 | 3 | <1% |

类型错的根因在 `PosType()`：`aspect ≥ 1.3` 兜底判 OPEN 是**绝对量纲**（没除线宽），细线上任何缺口都满足 → 训练集 Pred 分布 OPEN 2202 / MOUSEBITE 364，而 GT 是 1283 / 1379，鼠咬被吞掉 74%。

第二个独立损失在排序：检出 F 97.0% 而 mAP11 仅 89.3%，`PcbIcdarEvaluator` 里 `Conf = 候选面积`。

### 机制

1. **分型树**（`PcbTypeTree`）：判据全部线宽归一化 ＋ 新增**实测铜切断度** `split`＝缺陷邻域内实测图铜的「第二/第一连通块面积比」。物理含义即开路与鼠咬的定义差别：开路把走线切断，鼠咬只啃一角、铜仍连通。训练集中位：open **0.90**、mousebite **0.00**、pinhole 0.01。
   - 缺铜侧：`surround ≥ 0.9725 → PINHOLE`；`split ≥ 0.55 → OPEN`；`bite ≥ 0.64 → OPEN`；余 MOUSEBITE。
   - 多铜侧：`localW ≤ 2.83 → COPPER`（邻域已无模板铜＝悬空铜渣）；`parts ≥ 2 → SHORT`；余 SPUR。
2. **置信度**（`PcbConfidence`）：logistic(ln 面积 / ln 均值差 / 边缘解释度 / 实心度 / ln 长宽比 / 包围度 / 咬深)，7 个常数硬编码，替换面积排序。

### 训练/验收纪律

- 拟合集：`data/full` 中**非** official_test 的 1000 对、6873 GT 框（dump 见 `reports/features_train2/`）。
- 验收集：`data/official_test` 500 对，**未参与任何阈值选择**。
- 5 折 CV：缺铜 95.3%、多铜 96.2%；train−CV 差 0.8pp（不过拟合）。

## v1.1.0：三条优化路线的实证证伪（2026-10-21）

**性质**：代码全部落地且**默认关闭**（`footprintTau=0` / `seedZ=0` / `subpixelGradient=false`），生产行为与 v1.0.0 **逐位等价**（hash `288c1c41…` 不变，四集旧金标本已通过的门不重跑）。本轮价值在于用 train1000 拟合集（1000 对 / GT 6873，按 official_test 划分留出）拿到三条路线的**否定性证据**，避免在上位验收集上盲调。

### 总结论（train1000 全量；base：检出 F 97.5% / 严格 F 93.0% / TP 6646+6339 / Pred 6762）

| 路线 | 机制 | 实测 | 结论 |
|---|---|---|---|
| C1 | FWHM 逐框足迹（\|diff\| 剖面 τ×峰值截断替代全局缩放） | τ=0.08：严格 15.6% / 检出 16.3%；τ≥0.15：12.9% / 13.6%；Pred 面积 204~231px² vs GT 1258 | **证伪** |
| D1 | 局部 z 通道加性种子（积分图 O(1) 滑窗 z 分数） | SeedZ∈{3,4,5,6,8}×ZWindow∈{48,64} 全部逐位等价 base；洪水档 +80 Pred 全 FP、**0 TP** | **证伪（结构性）** |
| E1 | 梯度补偿亚像素配准（LK 一步，不重采样） | 检出 F 94.3%（−3.2pp）/ 严格 90.0%（−3.0pp）/ TP −257 | **证伪（实测退化）** |

### C1：|diff| 剖面双峰，FWHM 抓不到标注足迹

- 20 对冒烟 + 1000 对全量：**τ∈[0.15,0.6] 输出逐位相同**（剖面断崖位于 0.08·peak 与 0.15·peak 之间）；τ=0.08 稍大但仍只占 GT 面积 19%（231 vs 1258px²），131 个 pred 完全落于 GT 内、**0 个包住 GT**。
- 物理：阈值化 blob 内 \|diff\| 呈「热核平台≈peak → 断崖 → 裙边<0.08·peak」结构；人类标注的完整足迹延伸到**亚阈值裙边**，不对应任何固定的 peak 分数比。计划文档「半高处对应标注完整足迹」的假设被实证否定。GrowBoxScale=1.5 全局缩放（中位边长比 1.20）已是该数据上的可行近似。
- 遗留：代码保留（默认 0，RecipeStore 四件套完整），换数据/换阈值口径可再评估。

### D1：z 通道在本数据上结构性空转

- **数学约束**：z=(ad−μ)/(σ+ε) 的 16×16 统计窗含缺陷自身，z 上限=√((1−f)/f)（f=缺陷占窗面积比）。z≥3 需 f≤10% → 16×16 窗只容 25px² 且对比度→∞；f≥20%（≥51px²）时 z 上限<2.2 永不可能触发。默认 ZEps=2.0 进一步垫高分母（平坦区需 ad≥15~21 才够 z=3，而配准残余 ad 难得超过 12）。
- **实测**：SeedZ∈{3,4,5,6,8} × ZWindow∈{48,64} × ZEps=0.5 全部逐位等价 base。管道经洪水测试验证**完好**（SeedZ=1/ZEps=0.1/zAbs=6 时正常 +80 候选），排除 plumbing bug。
- **洪水证明（闭环）**：最宽松档新增 80 候选**全部 FP、0 TP**——110 个零重叠漏检 GT 距最近 pred 100+px 且峰值 \|diff\| 在噪声底以下。洪水设置是一切更严档位的超集，超集 0 TP ⇒ 该路线家族不可能产出 TP。

### E1：补偿量级与缺陷信号同阶，实测退化

- 机制：d = test −(tempA + Gx·fx + Gy·fy)，fx/fy 为逐块常数 SAD 抛物线分数位移。
- train1000 全量：Pred 6762→6674、检出 TP 6646→6389（−257）、严格 F 93.0→90.0；IoU 中位 0.542→0.544（定位未改善）而召回崩塌——补偿项 Gx·fx 在铜边量级 ±15 灰度，与弱缺陷信号（12~30）同阶，分数位移噪声把真信号一起减掉。
- 结论：整数配准（`Align`）已是该信号尺度下的最优工作点；亚像素补偿需显著更准的分数位移场（本数据不可得）。

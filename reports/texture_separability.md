# S1 诊断：纹理/结构特征可分性 —— 已证伪

日期：2026-10-21 ·配方：`v1.2.1` hash `26d991859176a03ee31cc7d5b728d646`（未改动）
工具：`src/DeepPCBStation.Core/Eval/PcbTextureSeparability.cs`，入口 `dotnet run --project src/DeepPCBStation.ConsoleDemo -c Release -- --tex-sep --samples=<集>`
产物：`reports/tex_sep_20261021_191936/`（train1000）、`reports/tex_sep_20261021_1921*`（mixed）

---

## 结论

**纹理/结构能量特征无法区分「漏检真缺陷」与「过杀鬼影」。该方向证伪，不得再提议纹理特征闸门。**

---

## 方法

POS（漏检真缺陷）= 未命中 GT 且能对应上被拒 blob 的目标（144个，配v1.2.1）。
NEG（过杀鬼影）= `MatchOneToOne` 下未匹配到任何 GT 的 pred（口径与 `PcbFpAuditor` 一致）。

对每个区域，取**框内双极性差分 ≥ DiffThreshold 的像素作 ROI**（两类同口径，避免正常像素稀释信号），在 test 图上算 7 维结构特征：Sobel 梯度均值/p95、Laplacian 均值、边缘密度、32-bin Shannon 熵、灰度极差、锐度（p95/均梯度比，近似跃变宽度倒数）。
可分性用 Mann-Whitney U 算 AUC（0.5=不可分，≥0.75 才算可用维度）。

---

## 结果

| 特征 | AUC (train1000, n=144/33) | AUC (mixed) |
|------|------|------|
| Sharpness | 0.617 | 0.440 |
| GradMean | 0.403 | 0.658 |
| LapMean | 0.378 | 0.658 |
| GradP95 | 0.454 | 0.655 |
| EdgeDensity | 0.421 | 0.647 |
| Entropy | 0.369 | 0.502 |
| Range | 0.354 | 0.320 |

**两集最强 AUC 仅 0.617 / 0.658，均低于 0.75 门槛。**

**更致命的是符号不稳定**：`GradMean`/`LapMean`/`GradP95` 在 train1000 上 AUC < 0.5（真缺陷梯度**更弱**），在 mixed 上却 > 0.65（真缺陷梯度**更强**）。同一特征在两个集上给出相反的判别方向，说明它捕捉的是**数据集/构图差异而非缺陷性质**。

---

## 附带发现

- POS 的 ROI 差分像素中位 **40**（p25=24 / p75=75），NEG 中位 **130**（p25=90 / p75=253）。鬼影候选的差异面积**系统性地大于**真缺陷——但这是**尺寸层面的差异，不是性质差异**，且方向与「过杀」矛盾（鬼影更大却不是缺陷），单靠它分不开。
- POS 按漏检原因细分显示：`aspect` 组（n=2）全部特征接近 0，说明这两个blob 的框内几乎没有差分像素，是**空blob 被aspect 闸杀掉**——属另一类问题，样本太少不���结论。
- `Range` 中位POS=255/224、NEG=255，再次印证：源数据近二值，**灰度幅值维度没有可用信息**。

## 影响与后续

1. **P0-2（纹理特征闸门）取消**，不得进入 S2。本仓在「不上 DL」约束下的判别性提升空间比方案预估的更窄。
2. 该工具保留在仓内作为**回归护栏**：任何后续改动若声称引入新判别信息，须先用 `--tex-sep` 证明 AUC ≥ 0.75，否则视为无增益。
3. 剩余可行动作（按性价比）：
   - **P1-1 修 `selectMin=Math.Min(minOpen,minMb)` 架构缺陷**（`HalconPcbDefectDetector.cs:144`）——这是**纯逻辑错误**，不依赖任何新信息，area<min 组 36 个漏检可直接回收。
   - **P0-1 多金板 σ容差场**—— 治的是**过杀**，路径与本诊断独立，仍成立，但需产线提供良品。
   - **P2 三态输出 + 采集有效性自检** —— 把「失焦/过曝/配准失败」从过杀里剥离，是工业必备且不改判定。
